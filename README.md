# CaterFlow Employer - Catering Gig & Staff Management 📋👨‍🍳

The CaterFlow Employer portal built with Flutter for catering vendors, wedding coordinators, and hospitality managers to create event shifts, hire verified staff, and track event check-ins.

![License](https://img.shields.io/badge/License-MIT-blue.svg)

---

## 🌟 Capabilities

- **Post Event Gigs**: Schedule shifts with reporting times, roles required, venue maps, and budget.
- **Applicant Review & Hiring**: Screen worker profiles, ratings, and experience in real time.
- **Attendance Verification**: Check in crew members on-site at the event.
- **Firebase Integrated**: Real-time synchronization via Google Firebase and Cloud Firestore.

## 🚀 Setup & Execution

```bash
git clone https://github.com/Rishi0073/caterflow-employer.git
cd caterflow-employer
flutter pub get
```
